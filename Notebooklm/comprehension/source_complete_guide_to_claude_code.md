## Description
A comprehensive guide to managing "Agentic Workflows" in the terminal. It covers PRP (Product Requirement Prompts), sub-agents, and life in the terminal.

## Concept
The terminal is the "Operating System" for AI agents. By integrating shell tools with the AI's agentic capabilities, developers can move 10x faster.

## Implementation

### Patterns
1. **PRP (Product Requirement Prompt)**: A structured way to describe a feature request so the agent has all necessary context (Requirements, Constraints, Edge Cases, Tech Stack).
2. **Sub-Agent Spawning**: Using the main agent to coordinate smaller sub-agents for parallelized work (e.g., one agent writes tests, another writes the implementation).
3. **Context Engineering**: Proactively managing the files "read" by the agent to avoid context overflow while maintaining deep coherence.
