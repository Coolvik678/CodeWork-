# Master Script Prompt Template

Use this prompt template every time you write a script for a new stickman documentary video.

---

## Directives & Execution Rules (STRICT MANDATE)
1. **Target Video Duration:** **6.5 to 8 Minutes (1,000–1,200 Words). NEVER WRITE SHORT 2-MINUTE SCRIPTS.**
2. **Mandatory Standalone Voiceover File (`voiceover_tts.txt`):**
   - Always output a clean standalone text file `voiceover_tts.txt` saved in `Remotion/videos/<video_slug>/voiceover_tts.txt`.
   - **STRICT CHARACTER LIMIT:** Must be **AROUND 6,000 CHARACTERS (5,800 TO 6,400 CHARACTERS, MAXIMUM CEILING 6,500 CHARACTERS)**.
3. Sentence-by-Sentence Timestamps: Map all visual scenes to exact spoken sentence beats in Part A of `script.md`.
4. High Scene Cut Density: 45 to 60 visual scenes per video.
