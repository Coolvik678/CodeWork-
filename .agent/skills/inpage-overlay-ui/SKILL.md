# In-Page Overlay UI Skill

## Core Principles

1. **Floating Collapsible Container**:
   - Fixed position on right side (`position: fixed; top: 12px; right: 12px; z-index: 999999;`).
   - Include a floating toggle button (`⚡`) to collapse panel to a tiny icon or expand to full panel (360px wide).

2. **Zero Blur Disappearance**:
   - Because the overlay panel is embedded in the web page DOM, clicking anywhere on the web page or in other windows does NOT cause the panel to close or disappear.

3. **High Contrast Dark Aesthetics**:
   - Dark palette (`#0f1117`, `#181b24`, `#212530`), smooth borders, glowing accent badges, rounded pill toggles.
