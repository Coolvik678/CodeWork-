## Description
This source outlines five non-obvious ways to use agentic coding tools beyond simple code generation: Automated Debugging, Legacy Refactoring, Documentation Generation, Dev Container Orchestration, and GitHub Issue Resolution.

## Concept
Treating the AI agent as a "Junior Engineer" that can execute the entire development lifecycle (Task -> Environment -> Execution -> Verification -> PR).

## Implementation

### Patterns
1. **Automated TDD Loop**: Ask the agent to find the failing test, fix the code, and rerun the test until it passes.
2. **Bulk Documentation**: Scan the repository and generate context-aware documentation for all modules.
3. **Issue-to-PR Flow**: Give the agent a GitHub Issue URL and have it perform the entire fix autonomously.
